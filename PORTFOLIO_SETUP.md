# Portfolio Setup - Ali Faiz

Before running the n8n workflow, configure your own:

- Google Sheets OAuth credential
- Google Sheet ID and sheet name
- Failure-prediction FastAPI endpoint
- Failure-type FastAPI endpoint
- Google Gemini credential
- Telegram credential and chat ID

The included workflow has been sanitized: original credential bindings, Google Sheet identifiers, Telegram destination, n8n instance metadata, and temporary ngrok URLs were removed.
